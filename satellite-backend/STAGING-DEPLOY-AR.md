# اختبار خرائط أور الذكية قبل النشر

## الوضع الحالي
- لوحة المؤشرات: `agricultural-indicators.html`
- خادم الصور التجريبي: `satellite-backend/worker.staging.js`
- إعداد النشر التجريبي: `wrangler.staging.jsonc`
- الخادم الإنتاجي `ur-smart-satellite` **يجب عدم استبداله أو تعديل أسراره**.
- **لا توجد نتيجة اختبار موثقة من Sentinel-2 حتى الآن.**

## تجهيز خادم الاختبار
1. أنشئ Worker منفصلاً باسم `ur-smart-satellite-staging` عبر `npx wrangler deploy --config wrangler.staging.jsonc` بعد إعداد صلاحيات Cloudflare المناسبة.
2. اضبط أسرار Worker التجريبي فقط: `SENTINEL_CLIENT_ID` و`SENTINEL_CLIENT_SECRET`، والمتغيرات `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` و`ALLOWED_ORIGIN=https://urfarmiq.github.io`. لا تحفظ أي أسرار في GitHub أو في صفحات HTML.
3. تحقق من عنوان Worker الفعلي. العنوان المكتوب في الواجهة افتراضي وقد لا يطابق الحساب الذي نُشر فيه Worker.
4. سجّل دخول المزارع واختر حقلاً ذا حدود محفوظة؛ اختبر طلب NDVI/NDMI الرقمي ثم الصور الثلاث عبر الحساب المصرح له.
5. راجع تاريخ الصورة والتغطية السحابية ودقة العينات. صورة PNG لا تعني وحدها أن البيانات تصلح لاتخاذ قرار زراعي.
6. لا تدمج طلب السحب ولا تنشر على `main` قبل إتمام اختبار حقيقي ناجح.

## اختبارات الأمان
- الطلب بلا `Authorization` يجب أن يرجع 401.
- الحقل غير المملوك للمستخدم يجب ألا يكشف حدوداً أو صوراً.
- قيم `visualization` غير المعروفة يجب أن ترجع 400.
- لا تعرض بيانات وهمية في حالة 401/403/422/502.
- استخدم `POST` فقط لطلبات التحليل، وتأكد من CORS للموقع الرسمي.

## القيود العلمية
- NDVI وNDMI متوسطات طيفية أو خرائط مؤشر؛ ليست تحاليل NPK أو pH أو رطوبة التربة الدقيقة.
- NDRE وSAVI وEVI وLST تتطلب حسابات ومصادر إضافية قبل تفعيل قراءات حقيقية.
- لا يوجد حتى الآن ربط openEO مؤكد؛ المسار الجاري يعتمد على Sentinel Hub.
