# UR Smart — Sentinel-2 Field Monitoring

هذا العامل الخلفي منفصل عن GitHub Pages. يتحقق من جلسة المزارع في Supabase، ويقرأ حدود حقله وفق سياسات RLS، ثم يطلب إحصاءات Sentinel-2 L2A من Sentinel Hub.

## سجل الطقس والري والتوصيات

- تُخزن الرصدات في `satellite_observations` وسجلات الري في `field_irrigation_logs` عبر migration `20261022121500_field_weather_irrigation_satellite_history.sql`.
- تتضمن التوصية الإرشادية NDVI/NDMI، المطر وET₀ للأيام السابقة، المطر المتوقع، ووقت/كمية الري المدخلة. تعرض سببها ومؤشر اكتمال وحداثة البيانات، وليس احتمالًا لصحة التوصية أو تشخيصًا مؤكدًا.
- يلزم التحقق ميدانيًا من رطوبة التربة قبل قرار الري. بيانات الطقس نموذجية مكانية، وليست محطة طقس داخل الحقل.

## الإعداد

1. أنشئ OAuth client في Copernicus Data Space Ecosystem مع صلاحية Sentinel Hub Statistical API.
2. أضف أسرار Cloudflare Worker:
   - `SENTINEL_CLIENT_ID`
   - `SENTINEL_CLIENT_SECRET`
3. أضف متغيرات Worker:
   - `SUPABASE_URL`
   - `SUPABASE_PUBLISHABLE_KEY`
   - `ALLOWED_ORIGIN=https://urfarmiq.github.io`
4. تأكد أن صفحة `satellite-analysis.html` تشير إلى عنوان العامل المنشور.
5. أضف حدًا للطلبات وحصة استخدام في Sentinel Hub قبل فتح الخدمة للجمهور.

لا تحفظ بيانات Sentinel أو Cloudflare السرية في GitHub أو صفحات HTML، ولا ترسلها عبر المحادثة.

## التحليل وجودة العينة

- تُقرأ حدود الحقل المحفوظة في `field_boundaries` وتُحوّل إلى نظام UTM بالمتر قبل طلب الدقة المكانية.
- تبدأ المعالجة بآخر 65 يومًا، وتتوسع إلى 180 يومًا إن لم تتوفر بكسلات صالحة. تُرجع سلسلة يومية للمؤشرات وجودة العينة، وتختار أحدث تاريخ يتوفر فيه 3 بكسلات صالحة على الأقل؛ إن لم يوجد، تستخدم أعلى عدد بكسلات صالحة متاح. يظهر تاريخ المشهد وتوضيح قدمه للمستخدم.
- تُستبعد فئات انعدام البيانات والبكسلات المعيبة والسحب والظلال والثلوج عبر SCL، مع استبعاد البكسلات خارج المضلع؛ الماء ليس مستبعدًا من جميع المؤشرات.
- تُرجع الخدمة 16 مؤشرًا من الانعكاسات الطيفية للمشهد نفسه: NDVI وNDMI وSAVI وOSAVI وMSAVI2 وEVI وGNDVI وNDRE وMNDWI وNBR وMSI وCIgreen وNDRE2 وNDRE3 وCIrededge وNIRv.
- تعرض واجهة التحليل صورة Sentinel‑2 حقيقية اللون داخل خريطة Leaflet، مع طبقات مؤشرات بكسلية وحدود الحقل وخيار اختيار تاريخ المشهد. تُحمّل صور PNG من العامل وتُلوّن للعرض، ولا يُستبدل غيابها بلون موحد مشتق من المتوسط. قراءة اللمس والماوس تقريبية بسبب ترميز العرض 8 بت والقص عند أطراف المقياس.
- دقة الإحصاءات 20 مترًا لأن مجموعة النطاقات تتضمن B05 وB06 وB07 وB8A وB11 وB12 وSCL بدقة مصدرية 20م.
- لا تُرجع توصية مؤكدة للري أو التسميد؛ المتوسطات الفضائية لا تقيس رطوبة التربة أو NPK مباشرة.

تُحفظ السلاسل الفضائية والطقس المرتبط بها وسجل الري في جداول Supabase ذات RLS، وتبقى صلاحية كل سجل لصاحب الحقل. الطقس التجريبي يأتي من Open‑Meteo ويجب نسب مصدره؛ واجهته المجانية غير مخصصة للاستخدام التجاري.
