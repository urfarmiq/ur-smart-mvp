# UR Smart | أور الزراعية الذكية

منصة عربية لإدارة الحقول الزراعية ومتابعتها. الموقع المنشور: [urfarmiq.github.io/ur-smart-mvp](https://urfarmiq.github.io/ur-smart-mvp/).

## الخدمات الموجودة

- إنشاء حساب المزارع وتسجيل الدخول.
- إضافة الحقول وتعديلها وحذفها من لوحة المزارع، مع حفظها في Supabase.
- تحديد حدود الحقل على الخريطة وحساب المساحة والمحيط، وحفظ الحدود في `field_boundaries`.
- إنشاء تقرير أولي عن الحقل وتسجيل التوصيات الإرشادية ضمن حدود البيانات المدخلة.
- حساب مؤشرات طيفية يدويًا، أو طلب قراءة حقيقية NDVI وNDMI من Sentinel-2 عند تهيئة الخدمة.
- سجل محلي لقراءات التحليل الفضائي على الجهاز المستخدم.

## تهيئة التحليل الفضائي

يُنشَر العامل منفصلًا عن صفحات GitHub Pages. اتبع [تعليمات العامل](./satellite-backend/README.md). لا تضع أسرار Sentinel Hub أو Cloudflare داخل ملفات HTML أو GitHub.

تعمل حدود الحقول عبر ترحيل Supabase الإضافي [20261017_field_boundaries.sql](./supabase/migrations/20261017_field_boundaries.sql). الترحيل يستخدم `IF NOT EXISTS` وسياسات RLS ولا يحذف الجداول أو البيانات الموجودة.

## ملاحظات الدقة

قراءات NDVI وNDMI هي متوسطات بكسلات Sentinel-2 الصالحة ضمن حدود الحقل. اختيار المشهد يعتمد على عدد البكسلات الصالحة، وتاريخ الرصد وجودة التغطية. المؤشرات لا تكفي وحدها لتحديد الري أو جرعات الأسمدة؛ يلزم التحقق الحقلي ونوع المحصول ومرحلة نموه وبيانات التربة والماء.

تُخزّن قراءات السجل الحالي محليًا على الجهاز. لا تُرفع تلقائيًا إلى Supabase.


## استكمال العمليات والمستشعرات — 25 أكتوبر 2026

- صفحة `operations.html` مرتبطة بلوحة المزارع: سجل محلي منفصل لكل حساب وحقل، بحث، تصدير واستعادة JSON وطباعة PDF. السجل العام لا تتم مزامنته سحابيًا؛ سجلات الري الموجودة تُعرض من Supabase دون تغييرها.
- تعرض الصفحة آخر 20 قراءة من `sensor_readings` مع تمييز `is_simulated`، وتوفر محاكاة تعليمية محلية لا تُكتب إلى جدول القياسات ولا تشغل الري. وجود الجدول لا يعني توصيل أجهزة فعلية.
- إصلاح نموذج المحاصيل بعد حفظ/إلغاء التعديل، وإضافة ملخص الحقول والمساحة. عمليات التعديل والحذف تتحقق من إرجاع الصف لتجنب عرض نجاح عند عدم تعديل أي صف.
- إصلاح طلب حزمة SCL لطبقات المؤشرات كي يعمل قناع السحب كما هو مقصود؛ يحتاج نشر العامل الخلفي عبر سير العمل الموجود.
- لم تتغير مفاتيح Supabase أو الحسابات أو مخططات الجداول، ولم تُحذف بيانات. لا توجد إضافة خدمات مدفوعة أو OpenAI API.

التحقق الآلي: `node --test tests/*.test.mjs` ثم `python tests/check_pages.py`. لا تعوض هذه الفحوص اختبار تسجيل دخول فعلي ورسم الحدود على الهاتف أو تحققًا ميدانيًا من القراءات الزراعية.

## إصلاح ظهور صور المؤشرات

- تجميع إحصاءات Sentinel-2 يبدأ الآن من منتصف الليل UTC، لتطابق يوم التحليل مع يوم طلب الصورة.
- تحميل الصور آمن للصور المخزنة مؤقتًا وبمهلة محدودة، مع تلوين طبقات المؤشرات الرمادية للعرض فقط.
- فشل طبقة واحدة لا يحجب الصور المتاحة. لا ينتظر عرض الصور تحميل الطقس أو حفظ السجل.
- تنظيف خرائط Leaflet والمهام المؤجلة عند التحديث، واختيار تاريخ موجود ضمن مشاهد الحقل المختار.
- لا تُستبدل الصورة المفقودة بلون موحد مشتق من المتوسط. توضّح الرسائل وجود خلفية مرجعية فقط أو غياب البكسلات الصالحة.

اختبار `tests/browser_satellite.py` يستخدم Chromium وPlaywright وLeaflet 1.9.4 ببيانات دخول ومضلعات وصور PNG اصطناعية، ولا يدخل إلى حساب إنتاجي أو يغيّر بياناته. يختبر عرض الطبقات في الصفحتين وعلى مقاسي هاتف وحاسوب، وإعادة التحميل، وفشل طبقة اختيارية والطقس. يحتاج ملفات Leaflet JS/CSS في `/tmp/ur-leaflet.js` و`/tmp/ur-leaflet.css` من unpkg.com/leaflet@1.9.4/dist/. هذا اختبار لمسار العرض وليس إثباتًا لوصول صورة حقيقية لحقل المستخدم؛ ذلك يحتاج جلسة دخوله واختيار مشهد صالح.
